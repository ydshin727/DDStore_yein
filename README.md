## 🎯 프로젝트 개요

<details>
  <summary><b>선정 배경 및 기획 의도</b></summary>
  
  최근 1인 가구의 급증과 함께 반려동물을 가족처럼 여기는 '펫 패밀리'가 늘어나며 **1,500만 반려 시대**가 열렸습니다.
  특히 국내 펫 푸드 시장이 9천억 원 규모로 성장하고, 이 중 **78%가 온라인**에서 거래된다는 점에 주목했습니다. 

  저희는 수많은 반려동물 중에서도 약 **75%의 압도적 비중을 차지하는 '반려견'** 유저들에게 집중했습니다.
  기존 대형 플랫폼의 복잡한 정보 과부하에서 벗어나, 반려견 보호자가 가장 쉽고 빠르게 필요한 물건을 찾을 수 있는 **버티컬 커머스(Vertical Commerce)** 를 지향합니다.
  
</details>

<details>
  <summary><b>활용 방안 및 기대 효과</b></summary>

  단순한 쇼핑몰을 넘어, 사용자가 머물고 싶은 환경을 만들기 위해 기술적으로 고민했습니다.

  * **앱처럼 매끄러운 쇼핑 경험**
    * React 기반의 SPA(Single Page Application)로 구현하여, 페이지 전환 시 끊김 없는 사용자 경험(UX)을 제공합니다.
  * **언제 어디서든 완벽한 화면**
    * 반응형 웹 디자인을 적용해 데스크탑은 물론, 산책 중 모바일 기기에서도 제약 없이 쇼핑을 즐길 수 있습니다.
  * **사용자 중심의 가치 창출**
    * 직관적인 인터페이스를 통해 사용자의 쇼핑 스트레스를 줄이고, 실제 구매로 이어지는 **전환율을 극대화**하는 비즈니스 모델을 구축했습니다.

</details>

  <summary><b>추천 상품</b></summary>

  ### 주요 기능
  * 결제 전·후 주요 구매 시점에 추천 상품 모달 표시
    * 상품 상세 페이지에서 **바로 결제** 클릭 (장바구니가 비어있는 경우)

  * 추천 상품 클릭 시 해당 상품 상세 페이지로 이동

  * 남은 상품 중 랜덤으로 2개를 추출하여 추천

<details>
  <summary><b>주문 및 결제</b></summary>

  ### 주요 기능
  * 상품 상세 페이지에서 **바로 결제** 지원
    * 장바구니에 상품이 있는 경우 함께 주문 여부 확인
    * 함께 주문 시 장바구니에 상품 추가 후 장바구니 페이지로 이동
    * 바로 주문 시 추천 상품 모달 표시 후 결제 진행
  * 주문 확인 페이지에서 주문 상품 목록 확인
  * **회원정보와 동일** 버튼 클릭 시 로그인한 회원의 이름, 이메일, 주소 자동 입력
  * 결제 수단 및 상품 수령 방법 선택 시에만 결제 가능
  * 매장 수령 선택 시 방문 지점까지 선택해야 결제 가능
  * 결제 완료 후 주문 내역 생성 및 추천 상품 모달 표시
  * 주문 상세 페이지로 이동하여 주문 정보 확인

  ### 주문 내역
  * 전체 주문 내역과 상세 주문 내역 (최신 주문순으로 정렬)
  * 배송 방식에 따라 **주문 상태 Progress Bar** 표시
    * 배달 : 주문완료 → 주문확인 → 배송중 → 배송완료 → 수령완료
    * 매장수령 : 주문완료 → 수령완료
  * 주문 상태에 따른 버튼 동적 표시
    * 주문 상세 보기 / 결제 취소 / 수령 완료
  * 관리자(Admin)가 배송 상태 변경 가능

  ### 구현
  * Redux Toolkit의 `createAsyncThunk`를 사용하여 주문 및 결제 관련 비동기 처리
  * 결제 완료 시 주문 DB 생성 및 장바구니 DB 자동 삭제
  * 로그인한 회원의 주문 내역만 조회하도록 구현
  * 주문 상태 변경, 결제 취소, 관리자 주문 관리, 매장 목록 조회 기능 구현
  * `addMatcher`를 활용하여 pending/fulfilled/rejected 상태 공통 처리
  * 주문 상품 없음 / 로딩 중 / API 오류에 대한 예외 처리 구현
